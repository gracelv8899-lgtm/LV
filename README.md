# 小红书爆文跟进工具（简版）

## 功能
- 每日爆文逻辑提示（固定方法论 + 当天日期）
- 新增爆文记录（标题、链接、粉丝、点赞、收藏、评论、优先级、阶段、备注）
- 按优先级、阶段筛选
- 一键过滤：互动总和>=1000、粉丝<=1000、评论>0
- 导出 CSV
- 本地存储（浏览器 localStorage）

## 文件结构
- `index.html`：页面结构
- `styles.css`：基础样式
- `script.js`：数据逻辑、筛选、导出 CSV

## 运行方式（Windows）
### 方式1：直接打开
1. 双击 `index.html`。
2. 在浏览器中填写表单并点击“新增记录”。
3. 点击“导出 CSV”下载文件。

### 方式2：本地静态服务（可选）
如果你安装了 Python：
```bash
python -m http.server 8000
```
然后打开 `http://localhost:8000`。
